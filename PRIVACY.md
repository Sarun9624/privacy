# Privacy Policy - Antigravity Workspace

Last updated: 2026-10-26

Antigravity Workspace is a personal, single-user tool. It is used only by its developer (Sarun) to read and manage his own Google Calendar and Google Drive data from a local computer.

## Data accessed
- Google Calendar events and Google Drive files of the signed-in Google account, only as needed for the task the user asks for.

## How data is used
- Data is fetched on the user's own machine through the Google APIs and used only to answer the user's own requests (for example, summarizing the day's calendar).
- Retrieved data may be passed to the user's own AI assistant session (Claude Code) as part of that request.

## Storage and sharing
- OAuth tokens are stored locally on the user's computer (`~/.config/google-workspace-mcp/`). They are never sent to the developer's servers because there are none.
- Data is not sold, shared with third parties, or used for advertising.

## Revoking access
- Access can be removed at any time at https://myaccount.google.com/permissions.
